# Cosmo Royal 1.1.0 — prototype

First public Cosmo package in this collection. The two pet files match the locally installed and hash-verified V1.1 build.

- Alternating manually keyed gait in both directions, with improved toe-off and recovery.
- Run baseline aligned with standing poses.
- More compact five-pose basketball backflip with the descending rotation included.
- Steady open playbook and balanced athletic work stance.
- Retained wave, idle, waiting, and corrected reaction scale.
- All 16 existing directional gaze poses preserved pixel-for-pixel.

Format: V2, 1536 × 2288 lossless RGBA WebP, 192 × 208 cells; 57 action frames, one neutral pose, and 16 gaze frames. Stable pet ID: `cosmo-royal-v1`.

Validation and ordered-frame visual review passed, with minor joint/proportion warnings. Local installation and file readback passed. Timed visual/live-app playback remains unverified; this is a prototype, not a claim of smoothness on every host. Browser preview control was unavailable during final review.

No executable installer, account settings, private logs, credentials, or automatic updater is included. Unofficial BYU mascot fan creation; no BYU or OpenAI endorsement.
