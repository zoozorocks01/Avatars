## Install

1. Download and unzip the package. No GitHub login, API key, or executable installer is needed.
2. In a compatible desktop app, open **Settings → Pets → Custom pets → Open folder**, if available. Menu names may differ. The Mac default observed during development is `~/.codex/pets/`; prefer the app's folder control.
3. Copy the extracted **cosmo-royal-v1** folder into the custom-pet folder. It contains only `pet.json` and `spritesheet.webp`.
4. Refresh the pet list, select **Cosmo Royal**, and show/wake him if hidden. If cached artwork persists, select another pet and return to Cosmo. Save your work before restarting the app yourself if needed.

This is a folder-based install, not a verified one-click ZIP import. If your app lacks local custom pets, stop and check compatibility. Other operating systems have not been verified.

## Update or roll back

Keep the stable folder **cosmo-royal-v1**, including for future versions. Before updating, back up its existing two files together **outside** the active pets folder. Replace only those two files, then refresh/reselect Cosmo. Preserve local customizations and other pets. To roll back, restore the backed-up pair and refresh/reselect.

Updates are requested by you; no automatic updater or scheduler is included. [catalog.json](../catalog.json) identifies the latest version and manifest.
